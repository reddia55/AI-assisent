# StudySpark — AI Study & Assignment Blogging Website A responsive static website concept for educational blogs, study resources, and assignment planning. ## Features- Responsive home page and navigation- Educational blog cards with summary pop-ups- Search/filter for blog topics- Study-plan helper for assignment outlines, revision checklists, and practice questions- No build tools required ## Files- `index.html` — website structure- `style.css` — layout and styling- `script.js` — search and interactive features ## Run locally Open `index.html` in a web browser. ## Publish with GitHub Pages 1. Sign in to GitHub and create a new **public** repository, for example `study-spark`. 2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder. 3. Open **Settings → Pages**. 4. Under **Build and deployment**, choose **Deploy from a branch**. 5. Select branch **main** and folder **/(root)**, then save. 6. Wait for GitHub Pages to publish. The repository's Pages section will show your website URL. ## Important note about AIThe study helper in this starter project is a local demo that creates templates in the browser. It does not connect to a real AI model. To add real AI, create a backend service and keep API keys on the server. Never put private API keys in `script.js` or any public repository. ## Customize Replace the sample blog posts with your own notes, change the site name/colors, and add links to your course resources.
